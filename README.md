# 16S Amplicon Kit

A modular Snakemake-based workflow for processing and analyzing 16S rRNA amplicon sequencing data. Please see the [documentation](https://ananya1006.github.io/16SAmpliconKit/) for more information on running the workflow.

## Associated Publication & Citation

These scripts were developed for the study below. If you use this workflow/scripts in your research, please cite:

Ghosh, A., Maile, A. & Nagarajaram, H.A. Prokaryotic co-occurrence patterns in diverse Indian mangrove ecosystems. Scientific Reports 15, 38283 (2025). https://doi.org/10.1038/s41598-025-18055-1
